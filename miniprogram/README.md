# 打包录像 - 微信小程序

## 使用步骤

### 1. 下载微信开发者工具
https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

### 2. 导入项目
- 打开微信开发者工具
- 点击 "导入项目" 或 "+" 
- 目录选择: `miniprogram/`
- AppID: 使用 `touristappid`（游客模式，无需注册）
- 项目名称: 打包录像

### 3. 配置服务器地址
修改 `app.js` 中的 `serverUrl` 为电脑的实际IP地址（默认: http://192.168.0.119:3456）

### 4. 预览测试
- 点击工具栏 "预览" → 生成二维码
- 用微信扫码 → 在手机上打开小程序

### 5. 操作流程
1. 点【📷 扫条码】→ 微信原生扫码 → 自动识别快递单号
2. 点【⏺ 开始录像】→ 调用后置摄像头录像
3. 点【☁️ 上传到电脑】→ 传到电脑服务器
4. 点【✅ 下一单】→ 继续下一个包裹

## 注意事项
- 手机和电脑需要在同一WiFi下
- 电脑需要先启动服务器: `npm start`
- 开发模式下需要点击开发者工具右上角 "详情" → "不校验合法域名"
